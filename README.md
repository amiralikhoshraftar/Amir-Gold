# Amir Gold

A modern, responsive gold jewelry store website designed and developed from scratch.

## About the Project

Amir Gold is a personal web development project created to practice and demonstrate my skills in building modern and responsive websites.

## Technologies

- HTML5
- CSS3
- Tailwind CSS
- Responsive Web Design
- Flexbox
- CSS Grid

## Features

- Responsive design for desktop and mobile
- Modern and clean user interface
- Gold jewelry product showcase
- Responsive navigation
- Structured and organized layout
